HOW IT WORKS

四步上手

顺序很重要：先有「生成能力」，再「生成皮肤」，最后「应用 / 恢复」。

  1. 1

    给 Agent 安装 skin-generator Skill

    把 workbuddy-skin-generator 这个 Skill 装进 WorkBuddy（用户级或项目级均可）。装好后，AI 才具备「看图生成皮肤」的能力。

  2. 2

    给 Agent 一张图，调用 Skill 生成皮肤

    在对话框里上传参考图（电影海报、游戏截图、配色图均可），说一句「帮我做个皮肤」。Agent 会自动取色、生成 .wbskin 并交给你。

  3. 3

    打开 WorkBuddy 皮肤管理器，应用皮肤

    双击打开管理器 App，把 .wbskin 拖入（或点「导入」），再点「应用」即可换肤。界面实时刷新，所见即所得。

  4. 4

    随时一键恢复默认皮肤

    想换回原样？在管理器里点「恢复默认」即可秒回官方主题。也可以继续导入其它皮肤自由切换。

FAQ

常见问题 & 踩坑指南

💻 安装 / 打开时提示「Apple 无法验证开发者」「未签名」怎么办？

这是因为当前 WorkBuddy 皮肤管理器 使用开发者自签名（ad-hoc），没有走 Apple 的正式公证（Notarization）。macOS 的 Gatekeeper 会拦截它——这不是软件有毒，是签名问题。三种解决方式：

方式一（推荐，最省事）：右键 → 打开

不要直接双击。在「应用程序」里右键点击「WorkBuddy 皮肤管理器」→ 选「打开」，在弹出的对话框里点「打开」。只需这样一次，之后双击就能正常启动。

方式二：系统设置里「仍要打开」

打开 系统设置 → 隐私与安全性，找到「WorkBuddy 皮肤管理器 已被阻止使用」的提示，点右侧的「仍要打开」。

方式三：终端清除隔离属性

打开终端，执行下面命令（把 App 名按实际路径调整）：

xattr -cr "/Applications/WorkBuddy 皮肤管理器.app"

执行后再次打开即可。

想彻底免提示？做正式签名 + 公证

如果你有 Apple Developer 账号，用 Developer ID Application 证书重签名并提交公证：

# 1) 用 Developer ID 证书签名
codesign --force --deep --sign "Developer ID Application: 你的名字" \
  "/Applications/WorkBuddy 皮肤管理器.app"

# 2) 提交公证
xcrun notarytool submit WorkBuddySkinManager.dmg \
  --keychain-profile "notary" --wait

# 3) 装订票据（让用户下载后也免拦截）
xcrun stapler staple "WorkBuddy 皮肤管理器.app"

需要我把打包脚本改成自动走 Developer ID 签名 + 公证，可以告诉我。

📦 皮肤导入后看不到背景图 / 显示异常？

请确认：① 文件是标准 .wbskin（本质是 ZIP，含 skin.json + theme.css + images/）；② 在管理器里导入后点过「应用」，而不是仅导入；③ 部分 skin 依赖 WorkBuddy 特定版本的 CSS 变量，如变量名有变动需微调。仍异常可回「恢复默认」。

🔁 重启 WorkBuddy 后皮肤没了？

皮肤注入是内存级的：重启 WorkBuddy 需重新应用。在管理器里再次点「应用」即可（管理器本身已记住你装了哪些皮肤）。后续版本会做开机自动重注。

🧩 skin-generator 怎么装到 WorkBuddy？

把下载的 workbuddy-skin-generator.zip 解压，得到的文件夹放到 WorkBuddy 的 Skills 目录（用户级 ~/.workbuddy/skills/ 或项目级 <项目>/.workbuddy/skills/），重启 WorkBuddy 即可在对话中调用。
