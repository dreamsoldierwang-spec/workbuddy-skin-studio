FAQ

常见问题 & 踩坑指南

💻 安装 / 打开时提示「Apple 无法验证开发者」「未签名」怎么办？

当前 WorkBuddy 皮肤管理器 使用开发者自签名（ad-hoc），没走 Apple 正式公证，macOS 会拦截——不是软件有毒，是签名问题。三种解决：

方式一（推荐）：右键 → 打开

在「应用程序」里右键点「WorkBuddy 皮肤管理器」→「打开」，弹窗里再点「打开」。只需一次，之后双击即可。

方式二：系统设置里「仍要打开」

系统设置 → 隐私与安全性，找到被拦截提示点「仍要打开」。

方式三：终端清除隔离属性

xattr -cr "/Applications/WorkBuddy 皮肤管理器.app"

📦 皮肤导入后看不到背景图 / 显示异常？

确认：① 文件是标准 .wbskin（含 skin.json + theme.css + images/）；② 导入后点过「应用」；③ 部分皮肤依赖 WorkBuddy 特定版本 CSS 变量。异常可回「恢复默认」。

🔁 重启 WorkBuddy 后皮肤没了？

皮肤注入是内存级的：重启 WorkBuddy 需重新应用。在管理器再次点「应用」即可（管理器已记住你装了哪些皮肤）。

🧩 skin-generator 怎么装到 WorkBuddy？

把 workbuddy-skin-generator.zip 解压，文件夹放到 Skills 目录（用户级 ~/.workbuddy/skills/ 或项目级 <项目>/.workbuddy/skills/），重启 WorkBuddy 即可。
